Dictionary data and licences

Last updated 28 September 2026

English definitions are built in. French and Spanish definition packs and translation packs are downloaded separately when selected. This page credits the sources used by those language resources; the app also shows source and license information.

Definitions and translations

The current English, French, and Spanish definition and translation data is derived from the corresponding language editions of Wiktionary, © Wiktionary contributors. English source data is from the 2026-09-02 dump; French and Spanish source data is from the 2026-09-01 dumps. The source data was extracted on 2026-09-27 by Kaikki / Wiktextract.

Extraction and changes

Structured data was extracted with Wiktextract, by Tatu Ylonen, “Wiktextract: Wiktionary as Machine-Readable Structured Data”, Proceedings of LREC 2022. Booktionary filtered language sections and restructured selected definitions, forms, and translation relations into separate SQLite files. The data has been modified. The pack catalog records the source editions, dump and extraction dates, license, and checksum for each file. Translation packs contain three independent directions for each pair: English ↔ French, English ↔ Spanish, and French ↔ Spanish.

Earlier French data

The French dictionary in app versions before the on-demand language release also used Morphalou 3.1 (ATILF / ORTOLANG), distributed under the LGPL-LR license. Morphalou is not included in the current French download pack.
